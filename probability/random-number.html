🔢 Random Number Experiment

Explore probability using random numbers.

📖 Learn the Concept

A random number experiment generates numbers without knowing which number will appear next. Each number in the selected range has an equal chance of being generated.

Example:
If the range is 1 to 5, there are 5 possible outcomes.

Probability of getting any particular number:
1 ÷ 5 = 0.2 = 20%
