📊 Mean, Median & Mode

Learn the three basic measures of central tendency.

📖 Learn the Concept

Mean, median and mode are used to describe the center of a set of data.

Mean = Sum of all values ÷ Number of values
Median = Middle value after arranging the data
Mode = Most frequently occurring value
