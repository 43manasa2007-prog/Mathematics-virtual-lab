📊 Histograms

Represent numerical data using continuous intervals.

📖 Learn the Concept

A histogram represents numerical data using continuous class intervals. The height of each bar represents the frequency of values in that interval.

Important:
Unlike a bar graph, the bars of a histogram touch each other because the intervals are continuous.

Example intervals: 10–20, 20–30, 30–40, 40–50
